Why this page has no server

Verification is a pure function over data you already hold. It needs no credential, because it grants nothing — and it must not need one, or the reproducibility claim reduces to trust the issuer's API.

The code here is a second, independent implementation of the published specification, written from the text rather than from the reference implementation. It passes the same public conformance vectors. That is the only real evidence a format is a standard rather than a description of one codebase — if the two ever disagree, at least one is wrong, and finding out which is the point.

The issuer never stored the values — only SHA-256 commitments to them. That is why you can check this, and why erasing the underlying facts does not invalidate any determination. A determination carries no subject identifier: it is about a decision, not a person.
