A decision about a person that anyone can check.

A determination record carries the rule that decided it, the digests of the facts it rested on, the clauses that carried the outcome, what would change it, and the issuer's signature. What a record contains

Not the values. A record commits to each fact by a digest of its value, so the institution's own data never has to leave the institution for the decision to be checked, and a record cannot be used to enumerate a population — there is no subject identifier in it, by design.

{
  "rule":        { "all": [ { "fact": "prior_refunds_90d", "op": "lt", "value": 3 }, … ] },
  "rule_hash":   "sha256 of the rule's canonical form",
  "rule_ref":    { "rule_id": "refund.eligibility", "legal_authority": "12 CFR 1026.13(e)", … },
  "facts":       [ { "fact": "prior_refunds_90d", "value_sha256": "…", "source": "core_ledger", … } ],
  "reasons":     [ { "path": "all[1]", "fact": "prior_refunds_90d", "op": "lt", "value": 3, "truth": "true" } ],
  "remedy":      { "target": "false", "sets": [ [ { "fact": "prior_refunds_90d", "constraints": [ … ] } ] ] },
  "signature":   { "kid": "…", "alg": "ed25519", "sig": "…" }
}

Evaluation is three-valued. A fact that was never attested is unknown, never false, and a determination cannot be sealed on an unknown. A rule that would be true whatever the facts said is refused before it can be sealed. There is no field in which an outcome can be asserted; the outcome is derived.

What the format does not do

  • It does not carry values, names or identifiers of the person. A verifier brings their own copy of the values.
  • It does not carry prose. A reason is a clause of the rule, located by its path; a remedy is a cell a fact must land in.
  • It does not say who issued a record unless the record is signed and you hold the issuer's key. An unsigned record is internally consistent at best.
  • It does not depend on the issuer still existing. Every step of verification runs from the record and your own files.

Two implementations

A reference implementation and an independent verifier written from the text alone, with no shared code, pass the same published vectors. When they disagree, at least one is wrong, and which is a question to answer rather than a number to adjust. The verifier on this site is the independent one.
